Options ​

Every function accepts the same flat options object. All fields are optional.

ts
similarity(a, b, { preset: 'music', threshold: 85, ignoreWords: ['live'] })

Presets ​

A preset is a ready-made set of options. Anything you pass yourself wins over it.

PresetForWhat it sets
musicsong titles, artistsstrip: ['featuring', 'version', 'brackets', 'articles'], replace: { '&': 'and', '+': 'and', n: 'and' }
searchsearch boxespartial: true, threshold: 70
strictcodes, referencesignoreWordOrder: false, ignoreSpaces: false, threshold: 90

Matching ​

OptionDefaultEffect
threshold80Minimum score to match.
ignoreWordOrdertruejohn smith matches smith john.
ignoreSpacestruestairwaytoheaven matches stairway to heaven.
partialfalseThe shorter text may match a part of the longer one, starting at a word. A full match always scores higher.
algorithm'smart'See How it works.

Normalization ​

Before comparing, both texts are cleaned up. normalize() shows the result.

OptionDefaultEffect
caseSensitivefalseKeep A and a apart.
accentSensitivefalseKeep é and e apart. Otherwise ligatures are expanded too: œ → oe, ß → ss.
punctuation'space''space': saint-malo → saint malo. 'remove': → saintmalo. 'keep': untouched. Apostrophes are removed outright: don't → dont.
strip[]Noise to drop, see below.
replace{}Whole-word replacements: { st: 'saint', nyc: 'new york city' }. st never touches stairs.
ignoreWords[]Whole words to drop: ['inc', 'ltd', 'sarl'].
numberstrueNumbers in words (English, French) and roman numerals become digits: two → 2, vingt et un → 21, XIV → 14, first → 1st. Single letters (I, X) stay. false with the search preset, so sev still finds Seven.

strip rules ​

RuleExample
featuringGet Lucky (feat. Pharrell) → get lucky
versionHey Jude - Remastered 2015 → hey jude, Song (Live) → song
bracketsSong [Bonus] (2012) → song
articlesThe Beatles → beatles, L'Aventurier → aventurier

A rule never empties a text: (Intro) stays intro.

Thresholds ​

ThresholdFeels like
95+Same text, maybe one typo in a long one
85A typo or two, good for strict answers
80Default: forgiving but rarely wrong
70Loose, good for search

Short texts move fast: one typo in a 4-letter word already costs 25 points. Use check()'s close verdict to be kind without accepting wrong answers.
