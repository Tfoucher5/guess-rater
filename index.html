guess-raterFuzzy matching that just works

Check answers, search as you type, spot names in a message, clean up duplicates, match two lists. Typos, accents, word order, numbers in words and noise like "(feat. X)" are handled for you.

🎯

Right by default

One smart score that forgives typos, swapped letters, accents, word order and missing spaces. On 3,000 simulated blind-test guesses, 97.6% of right answers were accepted and 0% of wrong ones.

🧰

One function per job

check() and checkAll() grade answers, search() and createIndex() power search boxes, closest() suggests corrections, find() spots text in a message, dedupe() and join() clean data.

⚡

Fast

Bit-parallel edit distances and pre-built indexes. Searching 26,000 songs takes about 40 ms per keystroke, about 5 times faster than Fuse.js on the same data.

🧠

Your editor knows it

Written in TypeScript. Every option autocompletes, and with objects, keys only accepts properties that hold text.

🪶

Tiny

About 6 kB minified and gzipped, zero dependencies. ESM and CommonJS, Node 18+ and every browser.

🎵

Presets for real data

The music preset drops featurings, "Remastered 2011", "(Live)" and leading articles. search turns on prefix matching. strict keeps order and spaces.

One line per use case ​

No configuration to learn before the first result.

Quizzes and blind tests ​

ts
check('bohemian rapsody', 'Bohemian Rhapsody')
// → { verdict: 'correct', score: 94.12 }
checkAll('bohemian rapsody de queen',
  { title: 'Bohemian Rhapsody', artist: 'Queen' })
// → { correct: true, found: ['title', 'artist'] }

Search as you type ​

ts
const index = createIndex(songs, {
  keys: ['title', 'artist'],
  preset: 'search',
})
index.search('zep stair') // → Stairway to Heaven

"Did you mean…?" ​

ts
closest('javascrpt', ['java', 'javascript'])
// → { item: 'javascript', score: 90 }

Spot a name in a message ​

ts
find("c'est bohemian rapsody non ?",
     'Bohemian Rhapsody')
// → [{ text: 'bohemian rapsody', start: 6 }]

Highlight what matched ​

ts
highlight('Bohemian Rhapsody', 'bohem')
// → [{ text: 'Bohem', match: true },
//    { text: 'ian Rhapsody', match: false }]

Clean up duplicates ​

ts
dedupe(['Hey Jude', 'hey jude - Remastered'],
       { preset: 'music' })
// → ['Hey Jude']

Match two lists ​

ts
join(['Apple Inc.', 'Microsoft Corp'],
     ['MICROSOFT CORPORATION', 'Apple'],
     { ignoreWords: ['inc', 'corp', 'corporation'] })
// → each row with its best match

Numbers, any way they're written ​

ts
similarity('2 Become 1', 'Two Become One') // → 100
check('rocky 2', 'Rocky II').correct       // → true

Simpler than v1 ​

Fewer concepts, flat options, one return type per function.

Before (v1) ​

js
const best = findBestMatch(guess, answers, {
  algorithm: 'hybrid',
  threshold: 85,
  normalize: { removeWords: ['feat', 'remastered'] },
})
const ok = best !== null && best.score >= 85

After (v2) ​

js
const { correct } = check(guess, answers, {
  preset: 'music',
})

Upgrading from v1 maps every old function and option.
